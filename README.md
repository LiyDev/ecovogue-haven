EcoVogue Haven 🌱



Plataforma de e-commerce sustentável desenvolvida como projeto acadêmico, com foco na comercialização de produtos eco-friendly e na conscientização sobre consumo sustentável.



Tecnologias

HTML5 · CSS3 · JavaScript



Funcionalidades



* Catálogo de produtos sustentáveis
* Componentes reutilizáveis
* Layout responsivo
* Formulário com validação
* Página de checkout
* Seleção de quantidade
* Cálculo de frete
* Cálculo automático do pedido
* Diferentes métodos de pagamento
* Animações de interface
