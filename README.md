# EcoVogue Haven 🌱

E-commerce sustentável desenvolvido como projeto acadêmico, com foco na venda de produtos eco-friendly e na conscientização sobre consumo sustentável.

## Funcionalidades

- Catálogo de produtos sustentáveis
- Componentes reutilizáveis (navbar, card de produto e rodapé)
- Layout responsivo com menu mobile
- Formulário de contato com validação (nome e e-mail)
- Página de checkout
- Seleção de quantidade
- Cálculo de frete
- Cálculo automático do pedido
- Diferentes métodos de pagamento
- Animações de interface

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

```
ecovogue-haven/
├── components/       # navbar.js, product-card.js, footer.js
├── index.html        # Página inicial e catálogo
├── checkout.html     # Página de checkout
├── checkout.js       # Lógica do checkout
├── script.js         # Menu mobile e validação do formulário
└── style.css
```

## Como executar

Não é necessário instalar nada:

```bash
git clone https://github.com/LiyDev/ecovogue-haven.git
cd ecovogue-haven
```

Abra o `index.html` no navegador. Se preferir, use a extensão Live Server do VS Code.
